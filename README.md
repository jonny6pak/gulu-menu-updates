# Gulu-Gulu Menu Generator updates

This project is for physical printing of draught/wine lists at Gulu-Gulu Cafe in Salem, MA. This app is of no use to anyone outside of the organization.  I have the source code private for now.  I may open source it later so anyone looking to print custom designed menus from Untappd could leverage it if they so desire.

This public repository is reserved for approved compiled application updates and signed update metadata. Application source and credentials are not distributed here.

**No staff-approved automatic updates are available yet.** Release signing, notarization, and trusted update configuration are still being prepared. Do not install test artifacts.

The application will retrieve approved updates automatically once that integration is released. Staff will not need GitHub accounts or repository access.
